Privacy policy

Personal assistant (Gmail) · Last updated: 2026-10-17

Who

This policy covers “Personal assistant (Gmail)”, a personal tool operated by Vincas Serva. It is used only by its owner and is not offered to anyone else.

What data the tool accesses

With the owner’s consent through Google sign-in, the tool can:

  • list and read messages in the owner’s Gmail mailbox;
  • create drafts in the owner’s Gmail mailbox.

The Google permission granted is “gmail.modify”, which is broader than the tool needs. The tool’s code uses it only to read messages and create drafts: it has no function to send or delete email. The owner sends drafts manually from Gmail.

How the data is used

The tool runs on the owner’s computer and works only when the owner asks. To summarise a message or prepare a draft, message content may be passed to the owner’s AI assistant (Claude, by Anthropic), and replies may be delivered to the owner’s private Telegram chat. Messages that look like security codes or bank notices are hidden by default.

Storage

  • The Google refresh token (used to obtain access) is stored only on the owner’s computer, encrypted with Windows DPAPI.
  • A local log keeps only the action, the message ID and the result code – no message content.
  • There is no server or database run by this site.

Sharing

Data is not sold, not used for advertising and not shared with anyone except the services named above, which the owner uses.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes the stored copy of the refresh token.

Privatumo politika

Asmeninis padėjėjas (Gmail) · Atnaujinta: 2026-10-17

Kas

Ši politika taikoma „Asmeniniam padėjėjui (Gmail)“ – asmeniniam įrankiui, kurį valdo Vincas Serva. Juo naudojasi tik savininkas, kitiems jis nesiūlomas.

Kokius duomenis įrankis mato

Savininkui sutikus per Google prisijungimą, įrankis gali:

  • matyti savininko Gmail laiškų sąrašą ir skaityti laiškus;
  • kurti juodraščius savininko Gmail dėžutėje.

Google suteikia leidimą „gmail.modify“, kuris platesnis, nei įrankiui reikia. Įrankio kodas jį naudoja tik laiškams skaityti ir juodraščiams kurti: funkcijos laiškams siųsti ar trinti jame nėra. Juodraščius siunčia pats savininkas iš Gmail.

Kaip duomenys naudojami

Įrankis veikia savininko kompiuteryje ir tik savininkui paprašius. Norint apibendrinti laišką ar paruošti juodraštį, laiško turinys gali būti perduotas savininko DI asistentui (Claude, Anthropic), o atsakymai – į privatų savininko Telegram pokalbį. Laiškai, panašūs į saugumo kodus ar banko pranešimus, pagal nutylėjimą nerodomi.

Saugojimas

  • Google prieigos atnaujinimo raktas (refresh token) saugomas tik savininko kompiuteryje, užšifruotas Windows DPAPI.
  • Vietiniame žurnale saugomas tik veiksmas, laiško ID ir rezultato kodas – be laiškų turinio.
  • Šis puslapis neturi jokio serverio ar duomenų bazės.

Dalijimasis

Duomenys neparduodami, nenaudojami reklamai ir neperduodami niekam, išskyrus aukščiau nurodytas paslaugas, kuriomis naudojasi savininkas.

Prieigos atšaukimas

Prieigą bet kada galima atšaukti myaccount.google.com/permissions. Ištrynus vietinį rakto failą, išsaugota rakto kopija panaikinama.
